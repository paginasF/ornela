# Control Diario - Ornela Cremoladas 🍦📊

Bienvenido al repositorio oficial de **Control Diario - Ornela Cremoladas**, una herramienta diseñada para llevar un registro, seguimiento y control administrativo eficiente de la producción, ventas y operaciones diarias del negocio de cremoladas.

## 🚀 Características Principales

* **Control de Ventas:** Registro detallado de las transacciones diarias.
* **Gestión de Stock:** Monitoreo de inventario y productos disponibles.
* **Interfaz Intuitiva:** Diseñado para facilitar la administración rápida y sin fricciones en el día a día.
* **Organización Financiera:** Resumen claro para el balance de ingresos y egresos.

## 🛠️ Tecnologías Utilizadas

Este proyecto está construido con tecnologías web modernas para garantizar velocidad, accesibilidad y facilidad de uso:
* **HTML5 / CSS3** para la estructura y diseño visual.
* **JavaScript** para la interactividad y la lógica de control diario.

## 📦 Instalación y Uso

Para ejecutar una copia local de este proyecto en tu equipo, sigue estos sencillos pasos:

1. Clona este repositorio en tu máquina:
   ```bash
   git clone https://github.com/tu-usuario/control-diario-ornela-cremoladas.git
   ```
2. Abre la carpeta del proyecto.
3. Ejecuta el archivo principal (`index.html`) en tu navegador web preferido.
